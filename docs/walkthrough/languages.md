# Listen in your own language

**Claude Code TTS: Languages and Translation** does two separate things.

**Speak everything in one language** translates each message locally before speaking it, into any of sixteen languages. The translation models are about 100 MB each and run offline afterwards. Technical words stay in English, because that is how developers say them.

**Set the voice for a language** gives one language a voice of its own. When Claude answers in it, that voice reads the answer, while everything else keeps yours.

Detection is automatic: Claude switching language mid-session switches the voice with it.
