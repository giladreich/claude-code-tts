# Hear Claude speak

Claude Code TTS is already listening. The next time Claude Code writes a reply in this window, you will hear it: prose is read aloud, code is not, and tool calls are announced ("Bash: run the tests").

Nothing leaves your machine. The voice runs locally, and the only network use is a download you start yourself.

Try it now: run **Claude Code TTS: Speak Selection** on any text, or ask Claude something and listen.

The status bar item on the right shows what is happening and opens the menu:

- `$(unmute)` listening
- `$(megaphone)` speaking (the number is how much is queued)
- `$(mute)` muted

**ctrl+alt+v** mutes and unmutes (**ctrl+shift+alt+v** on Windows and Linux).
