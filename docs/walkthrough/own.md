# Make it your own voice

**Claude Code TTS: My Voices** creates and manages voices.

- **Record** reads a short passage back to you, listens for about ten seconds, and checks that what you read matches the text before it saves.
- **From a file** takes any audio or video you already have, and lets you pick the stretch to learn from.
- **Design** builds a voice from a description ("a calm, low-pitched narrator"), with no recording at all.

A voice you create is used by both Qwen3 and Chatterbox, so it speaks whichever languages the engine you are using supports.

Only clone a voice you have the right to use: your own, or one whose owner agreed. The first clone asks you to confirm that.
