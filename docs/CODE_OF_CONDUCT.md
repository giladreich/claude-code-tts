# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, and keep discussion about the work. Harassment, personal attacks and unwelcome attention are not acceptable, in issues, pull requests or anywhere else this project is discussed.

Report anything that needs attention privately, through the "Report a vulnerability" flow on the Security tab or by contacting the maintainer through their GitHub profile. Reports are handled confidentially. The maintainer may edit, remove or reject contributions that do not follow this document, and may block accounts for repeated or serious behaviour.
